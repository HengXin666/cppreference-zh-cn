在标头 <ctype.h> 定义 
int isdigit( int ch );

检查给定的字符是否为数字字符（0123456789）。

若 ch 的值不能表示为 unsigned char 且不等于 EOF，则行为未定义。

参数

ch - 要分类的字符

返回值

若字符为数字则为非零值，否则为零。

注解

isdigit 与 isxdigit 是仅有的不受当前安装的 C 本地环境影响的标准窄字符分类函数，尽管一些实现（例如 Microsoft 于 1252 代码页）可能将额外的单字节字符分类为数字。

示例

运行此代码
#include <ctype.h>
#include <limits.h>
#include <stdio.h>
 
int main(void)
{
    for (int ndx=0; ndx<=UCHAR_MAX; ++ndx)
        if (isdigit(ndx))
            printf("%c", ndx);
    printf("\n");
}

输出： 

0123456789
