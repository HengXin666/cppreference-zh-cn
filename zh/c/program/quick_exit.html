在标头 <stdlib.h> 定义 
_Noreturn void quick_exit( int exit_code );
(C11 起)
(C23 前)		 
[[noreturn]] void quick_exit( int exit_code );
(C23 起)

导致程序正常终止，而不完全清理资源。

以注册顺序的逆序调用传递给 at_quick_exit 的函数。调用完注册的函数后，调用 _Exit(exit_code)。

参数

exit_code - 程序的退出状态

返回值

（无）

示例

运行此代码
#include <stdlib.h>
#include <stdio.h>
 
void f1(void)
{
    puts("pushed first");
    fflush(stdout);
}
 
void f2(void)
{
    puts("pushed second");
}

void f3(void)
{
    puts("won't be called");
}

int main(void)
{
    at_quick_exit(f1);
    at_quick_exit(f2);
    atexit(f3);
    quick_exit(0);
}

输出： 

pushed second
pushed first
