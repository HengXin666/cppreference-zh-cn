reverse_iterator rbegin();
(1) (C++11 起为 noexcept) 
const_reverse_iterator rbegin() const;
(2) (C++11 起为 noexcept) 
const_reverse_iterator crbegin() const noexcept;
(3) (C++11 起)

返回指向逆向的 multiset 的首元素的逆向迭代器。它对应非逆向 multiset 的末元素。如果 multiset 为空，那么返回的迭代器等于 rend()。

返回值

指向首元素的逆向迭代器。

复杂度

常数。

注解

因为 iterator 和 const_iterator 都是常迭代器（而且实际上可以是同一类型），故不可能通过任何这些成员函数返回的迭代器修改容器元素。

返回的逆向迭代器的底层迭代器是尾迭代器。因此在尾迭代器失效时，返回的迭代器也会失效。

libc++ 将 crbegin() 向后移植到 C++98 模式。

示例

运行此代码
#include <iostream>
#include <set>

int main()
{
    std::multiset<unsigned> rep{1, 2, 3, 4, 1, 2, 3, 4};

    for (auto it = rep.crbegin(); it != rep.crend(); ++it)
    {
        for (auto n = *it; n > 0; --n)
            std::cout << "⏼" << ' ';
        std::cout << '\n';
    }
}
