size_type max_size() const noexcept;
(C++23 起)

返回由于系统或库实现的限制，容器能够持有的最大元素数量。等价于 std::min<size_type>(c.keys.max_size(), c.values.max_size())。

参数

（无）

返回值

最大元素数量。

复杂度

常数。

注解

这个值通常反映的是容器大小的理论极限，最大为 std::numeric_limits<difference_type>::max()。在运行时，容器的大小可能由于可用 RAM 的总量而受限于某个小于 max_size() 的值。

示例

运行此代码
#include <iostream>
#include <flat_map>
#include <locale>

int main()
{
    std::flat_multimap<char, char> q;
    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << "std::flat_multimap 的最大大小为 " << q.max_size() << '\n';
}

可能的输出： 

std::flat_multimap 的最大大小为 768,614,336,404,564,650
