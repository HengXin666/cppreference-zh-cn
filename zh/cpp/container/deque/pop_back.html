void pop_back();

移除容器的末元素。

如果 empty() 是 true，那么行为未定义。

(C++26 前)

如果 empty() 是 true，那么：

  • 如果实现是硬化实现，那么就会发生契约违背。
  • 如果实现不是硬化实现，那么行为未定义。
 (C++26 起)

指向最后元素的迭代器和引用失效。end() 迭代器也失效。

复杂度

常数。

示例

运行此代码
#include <deque>
#include <iostream>

namespace stq {
template<typename T>
void println(auto, const T& xz)
{
    std::cout << '[';
    bool first{true};
    for (auto const& x : xz)
        std::cout << (first ? first = false, "" : ", ") << x;
    std::cout << "]\n";
}
}
 
int main()
{
    std::deque<int> numbers{1, 2, 3};
    stq::println("{}", numbers);
    while (not numbers.empty())
    {
        numbers.pop_back();
        stq::println("{}", numbers);
    }
}

输出： 

[1, 2, 3]
[1, 2]
[1]
[]
