(C++17 起)

返回视图中的 CharT 元素个数，即 std::distance(begin(), end())。

参数

（无）

返回值

视图中的 CharT 元素个数。

复杂度

常数。

示例

运行此代码
#include <iostream>
#include <string_view>

// 打印以单引号环绕的字符串、它的长度及其是否为空。
void check_string(std::string_view ref)
{
    std::cout << std::boolalpha
              << "'" << ref << "' 有 " << ref.size()
              << " 个字符；是否为空: " << ref.empty() << '\n';
}

int main(int argc, char **argv)
{
    // 空字符串
    check_string("");

    // 几乎始终非空：argv[0]
    if (argc > 0)
        check_string(argv[0]);
}

可能的输出： 

'' 有 0 个字符；是否为空: true
'./a.out' 有 7 个字符；是否为空: false
