static bool eq_int_type( int_type c1, int_type c2 );
(C++11 起为 constexpr)
(C++11 起为 noexcept)

检查两个 int_type 的值是否相等。

对字符特征的关于 X::eq_int_type 的通用要求参考字符特征 (CharTraits) 。

参数

c1, c2 - 要比较的值

返回值

在 c1 等于 c2 时返回 true，否则返回 false。

复杂度

常数。
