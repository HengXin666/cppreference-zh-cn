static char_type*
    copy( char_type* dest, const char_type* src, std::size_t count );
(C++20 起为 constexpr)

从 src 指向的字符串复制 count 个字符到 dest 指向的字符序列。

如果 [dest, dest + count) 和 [src, src + count) 重叠，那么行为未定义。

对字符特征的关于 X::copy 的通用要求参考字符特征 (CharTraits) 。

参数

dest - 指向要复制的字符串的指针
src - 指向复制来源的字符串的指针
count - 要复制的字符数

返回值

dest

异常

不抛出。

复杂度

与 count 成线性。

参阅

assign
[静态]
 赋值一个字符
