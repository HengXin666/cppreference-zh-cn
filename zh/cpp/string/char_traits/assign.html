static void assign( char_type& c1, const char_type& c2 );

(1) (C++11 起为 noexcept)
(C++17 起为 constexpr) 

static char_type* assign( char_type* ptr, std::size_t count, char_type c2 );

(2) (C++20 起为 constexpr)

1) 将 c2 赋给 c1，行为等同于 c1 = c2。
2) 将 c2 赋给 ptr 指向的包含 count 个字符的字符序列。

对字符特性的关于 X::assign 的通用要求参考字符特征 (CharTraits) 。

参数

c1 - 被赋值的字符
c2 - 要赋值的字符值
ptr - 指向被赋值字符序列的指针
count - 字符序列的长度

返回值

1) （无）
2) ptr

复杂度

1) 常数。
2) 与 count 成线性。
