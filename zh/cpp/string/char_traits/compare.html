static int compare( const char_type* s1, const char_type* s2,
                    std::size_t count );
(C++17 起为 constexpr)

比较字符串 s1 与 s2 的首 count 个字符，比较按字典序进行。

如果 count 为零，那么认为字符串相等。

对字符特征的关于 X::compare 的通用要求请参考字符特征 (CharTraits) 。

参数

s1, s2 - 指向要比较的字符串的指针
count - 要比较来自每个字符串的字符数

返回值

在 s1 小于 s2 时返回负值。

在 s1 等于 s2 时返回 0。

在 s1 大于 s2 时返回正值。

复杂度

与 count 成线性。
