在标头 <cwctype> 定义 
int iswblank( std::wint_t ch );
(C++11 起)

检查给定的宽字符是否被当前 C 本地环境分类为空格符（即用于在句中分隔单词的空白符）。默认 C 本地环境中，只有空格（0x20）和水平制表符（0x09）是空格符。

若 ch 的值既不能表示为 wchar_t 又不等于宏 WEOF，则行为未定义。

参数

ch - 宽字符

返回值

若宽字符是空格符则为非零值，否则为零。

注解

ISO 30112 定义 POSIX 空格字符为 Unicode 字符 U+0009、U+0020、U+1680、U+180E、U+2000..U+2006、U+2008、U+200A、U+205F 及 U+3000。

示例

运行此代码
#include <clocale>
#include <cwctype>
#include <iostream>

int main()
{
    wchar_t c = L'\u3000'; // 表意空格 ('　')

    std::cout << std::hex << std::showbase << std::boolalpha;
    std::cout << "默认本地环境中, iswblank(" << (std::wint_t)c << ") = "
              << (bool)std::iswblank(c) << '\n';
    std::setlocale(LC_ALL, "en_US.utf8");
    std::cout << "Unicode 本地环境中, iswblank(" << (std::wint_t)c << ") = "
              << (bool)std::iswblank(c) << '\n';
}

输出： 

默认本地环境中, iswblank(0x3000) = false
Unicode 本地环境中, iswblank(0x3000) = true
