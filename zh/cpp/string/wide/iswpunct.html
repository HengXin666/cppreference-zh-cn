在标头 <cwctype> 定义 
int iswpunct( std::wint_t ch );

检查给定的宽字符是否为标点，即 !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~ 之一或任何限定于当前 C 本地环境的字符。

若 ch 的值既不能表示为 wchar_t 又不等于宏 WEOF，则行为未定义。

参数

ch - 宽字符

返回值

若宽字符为标点字符则为非零值，否则为零。

注解

ISO 30112 指定哪些 Unicode 字符包含于 POSIX 标点类别。

示例

运行此代码
#include <clocale>
#include <cwctype>
#include <iostream>

int main()
{
    wchar_t c = L'\u2051'; // 双星号 ('⁑')

    std::cout << std::hex << std::showbase << std::boolalpha
              << "默认本地环境中, iswpunct("
              << static_cast<std::wint_t>(c) << ") = "
              << static_cast<bool>(std::iswpunct(c)) << '\n';

    std::setlocale(LC_ALL, "en_US.utf8");
    std::cout << "Unicode 本地环境中, iswpunct("
              << static_cast<std::wint_t>(c) << ") = "
              << static_cast<bool>(std::iswpunct(c)) << '\n';
}

输出： 

默认本地环境中, iswpunct(0x2051) = false
Unicode 本地环境中, iswpunct(0x2051) = true
