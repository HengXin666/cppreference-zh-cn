杂项
strerror
 
在标头 <cstring> 定义 
char* strerror( int errnum );

返回指向系统错误码 errnum 的文本表示的指针，它等同于 std::perror() 会打印的描述。

通常从 errno 对象获得 errnum，不过函数接受 int 类型的任何值。字符串的内容是本地环境限定的。

程序必须不修改返回的字符串，但对 strerror 函数的后继调用可能重写该字符串。不要求 strerror 为线程安全。实现可以返回指向静态只读字符串字面量的不同指针，或反复返回指向静态缓冲区的同一指针而 strerror 于该缓冲区中放置字符串。

参数

errnum - 指代错误码的整数值

返回值

指向对应 errno 错误码 errnum 的空终止字节串的指针。

注解

POSIX 允许对 strerror 的后继调用使先前调用所返回的指针值失效。它亦规定 LC_MESSAGES 本地环境刻面控制这些消息的内容。

POSIX 定义了一个称为 strerror_r 的线程安全版本。Glibc 定义了一个不兼容的版本。

示例

运行此代码
#include <cerrno>
#include <clocale>
#include <cmath>
#include <cstring>
#include <iostream>
 
int main()
{
    const double not_a_number = std::log(-1.0);
    std::cout << not_a_number << '\n';
 
    if (errno == EDOM)
    {
        std::cout << "log(-1) 失败：" << std::strerror(errno) << '\n';
        std::setlocale(LC_MESSAGES, "de_DE.utf8");
        std::cout << "德语错误信息：" << std::strerror(errno) << '\n';
    }
}

可能的输出： 

nan
log(-1) 失败：Numerical argument out of domain
德语错误信息：Das numerische Argument ist ausserhalb des Definitionsbereiches
