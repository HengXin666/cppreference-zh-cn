在标头 <system_error> 定义 
template< class T >
struct is_error_code_enum;
(C++11 起)

如果 T 是错误码枚举（例如 std::io_errc 和 std::future_errc），那么此模板提供等于 true 的成员常量 value。对于任何其他类型，value 是 false。

此模板可以为有程序定义的类型特化，以指示该类型适用 std::error_code 隐式转换。

辅助变量模板

template< class T >
constexpr bool is_error_code_enum_v = is_error_code_enum<T>::value;
(C++17 起)

继承自 std::integral_constant
