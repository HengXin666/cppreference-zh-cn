与 std::shared_ptr 相同的成员和非成员
 
template< class T > struct hash<std::experimental::shared_ptr<T>>;
(库基础 TS)

std::hash 对 std::experimental::shared_ptr<T> 的模板特化允许用户获取 std::experimental::shared_ptr<T> 类型对象的散列。

对于给定的 std::experimental::shared_ptr<T> p，此特化确保 std::hash<std::experimental::shared_ptr<T>>()(p) == std::hash<T*>()(p.get())。
