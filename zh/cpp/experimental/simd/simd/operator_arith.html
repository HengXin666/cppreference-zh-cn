逐元素对操作数的各元素运用给定的二元运算符。返回一个 simd，对于范围 [0, size()) 中的所有 i，第 i 个元素等于：

1) lhs[i] + rhs[i]
2) lhs[i] - rhs[i]
3) lhs[i] * rhs[i]
4) lhs[i] / rhs[i]
5) lhs[i] % rhs[i]
6) lhs[i] & rhs[i]
7) lhs[i] | rhs[i]
8) lhs[i] ^ rhs[i]
9) lhs[i] << rhs[i]
10) lhs[i] << n
11) lhs[i] >> rhs[i]
12) lhs[i] >> n

参数

lhs - 左操作数
rhs - 右操作数
n - lhs 中每个元素要位移的位数

返回值

如上所述的 simd。
