R operator->() const noexcept;
(2) (库基础 TS v3)
1) 访问作为指针的底层资源句柄所指向的对象或函数。此函数仅若 std::is_pointer_v<R> 为 true 且 std::is_void_v<std::remove_pointer_t<R>> 为 false 才参与重载决议。若资源句柄不指向对象或函数，则行为未定义。
2) 获取作为指针的底层资源句柄的副本。此函数仅若 std::is_pointer_v<R> 为 true 才参与重载决议。常用返回值访问被指向的对象。

参数

（无）

返回值

1) 底层资源句柄所指向的函数或对象。
2) 底层资源句柄的副本。
