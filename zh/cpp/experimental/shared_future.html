template< class T > class shared_future;
(1) (并发 TS) 
template< class T > class shared_future<T&>;
(2) (并发 TS) 
template<>          class shared_future<void>;
(3) (并发 TS)

类模板 std::experimental::shared_future 以下列操作扩展 std::shared_future：

  • 从 future<shared_future<T>> 构造的解包装构造函数；
  • 查询共享状态是否就绪的成员函数 is_ready；以及
  • 附着持续到 future 的成员函数 then。

std::experimental::shared_future 与 std::shared_future 间无交互。
