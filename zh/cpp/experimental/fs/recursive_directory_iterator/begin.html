recursive_directory_iterator begin( recursive_directory_iterator iter );
(1) (文件系统 TS) 
recursive_directory_iterator end( const recursive_directory_iterator& );
(2) (文件系统 TS)
1) 返回未改变的 iter。
2) 返回默认构造的 recursive_directory_iterator，它作为尾迭代器。实参被忽略。

这些非成员函数使得可以在基于范围的 for 循环中使用 recursive_directory_iterator。

参数

iter - recursive_directory_iterator

返回值

1) 未改变的 iter。
2) 尾迭代器（默认构造的 recursive_directory_iterator）。

异常

noexcept 规定：  
noexcept
  

示例

运行此代码
#include <experimental/filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    fs::create_symlink("a", "sandbox/syma");
    for (auto& p : fs::recursive_directory_iterator("sandbox"))
        std::cout << p << '\n';
    fs::remove_all("sandbox");
}

可能的输出： 

"sandbox/a"
"sandbox/a/b"
"sandbox/file1.txt"
"sandbox/syma"
