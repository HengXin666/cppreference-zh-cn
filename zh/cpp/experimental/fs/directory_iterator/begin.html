begin(directory_iterator)end(directory_iterator)
 
directory_iterator begin( directory_iterator iter );
(1) (文件系统 TS) 
directory_iterator end( const directory_iterator& );
(2) (文件系统 TS)
1) 返回未改变的 iter。
2) 返回默认构造的 directory_iterator，它作为尾迭代器。忽略实参。

这些非成员函数使得可以将 directory_iterator 用于基于范围的 for 循环。

参数

iter - directory_iterator

返回值

1) 未改变的 iter。
2) 尾迭代器（默认构造的 directory_iterator）。

异常

noexcept 规定：  
noexcept
  

示例

运行此代码
#include <experimental/filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    std::ofstream("sandbox/file2.txt");
    for (auto& p : fs::directory_iterator("sandbox"))
        std::cout << p << '\n';
    fs::remove_all("sandbox");
}

可能的输出： 

"sandbox/a"
"sandbox/file1.txt"
"sandbox/file2.txt"
