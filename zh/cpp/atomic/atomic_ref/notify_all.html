void notify_all() const noexcept;
(C++26 起为 constexpr)

进行原子提醒操作。

解除所有 *ptr 上的原子等待操作（即 wait()）阻塞的线程，如果存在）；否则不做任何事。 此重载只有在 std::is_const_v<T> 是 false 时才会参与重载决议。

注解

这种形式的更改检测通常比简单轮询或纯自旋锁高效。
