在标头 <atomic> 定义 
template< class T >
T atomic_fetch_min( std::atomic<T>* obj,
                    typename std::atomic<T>::value_type arg ) noexcept;
(1) (C++26 起) 
template< class T >
T atomic_fetch_min( volatile std::atomic<T>* obj,
                    typename std::atomic<T>::value_type arg ) noexcept;
(2) (C++26 起) 
template< class T >
T atomic_fetch_min_explicit( std::atomic<T>* obj,
                             typename std::atomic<T>::value_type arg,
                             std::memory_order order ) noexcept;
(3) (C++26 起) 
template< class T >
T atomic_fetch_min_explicit( volatile std::atomic<T>* obj,
                             typename std::atomic<T>::value_type arg,
                             std::memory_order order ) noexcept;
(4) (C++26 起)

以 obj 的旧值和 arg 的 std::min 结果原子地替换 obj 所指向的值。如同执行下列内容一般进行运算：

1,2) obj->fetch_min(arg)
3,4) obj->fetch_min(arg, order)

如果 std::atomic<T> 没有 fetch_min 成员（此成员仅对 bool 以外的整数和指针类型提供），那么程序非良构。

参数

obj - 指向要修改的原子对象的指针
arg - 与存储于原子对象的值 std::min 的值
order - 内存同步定序

返回值

*obj 的修改顺序中，紧接此函数生效之前的值。
