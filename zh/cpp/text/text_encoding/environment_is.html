template< id I >
static bool environment_is();
(C++26 起)

检查环境编码是否等于以指定值 I 为 MIBenum 值的编码。调用此函数等价于 return environment() == I;。

如果 CHAR_BIT 不是 8，则此函数被弃置。

模板形参

I - 要比较其值的 text_encoding::id

返回值

如果 environment() 等于 I 则返回 true；否则返回 false。
