saturating_cast
(C++26)
 
在标头 <numeric> 定义 
template< class T, class U >
constexpr T saturating_cast( U x ) noexcept;
(C++26 起)

将值 x 转换为 T 类型的值，并使得 x 夹在 T 类型的最小值和最大值之间。

如果 T 或者 U 不是有符号或者无符号整数类型（包括标准整数类型和扩展整数类型），则结果未定义。

参数

x - 整数

返回值

  • 如果 x 表示 T 类型的值，则返回 x。
  • 否则，返回 T 类型的最接近 x 的最大值或者最小值。

注解

可能的实现

参考 libstdc++ (GCC)。

示例

可以在 Compiler Explorer 上预览。

运行此代码
#include <cstdint>
#include <limits>
#include <numeric>

int main()
{
    constexpr std::int16_t x1{696};

    constexpr std::int8_t x2 = std::saturating_cast<std::int8_t>(x1);
    static_assert(x2 == std::numeric_limits<std::int8_t>::max());

    constexpr std::uint8_t x3 = std::saturating_cast<std::uint8_t>(x1);
    static_assert(x3 == std::saturating_cast<std::uint8_t>::max());

    constexpr std::int16_t y1{-696};

    constexpr std::int8_t y2 = std::saturating_cast<std::int8_t>(y1);
    static_assert(y2 == std::numeric_limits<std::int8_t>::min());

    constexpr std::uint8_t y3 = std::saturating_cast<std::uint8_t>(y1);
    static_assert(y3 == 0);
}
