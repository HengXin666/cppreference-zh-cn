在标头 <complex> 定义 
template< class T > 
complex<T> sin( const complex<T>& z );

计算复数值 z 的复正弦。

参数

z - 复数值

返回值

若无错误发生，则返回 z 的复正弦。

错误和特殊情况处理成如同运算以 -i * std::sinh(i * z) 实现，其中 i 是虚数单位。

注解

正弦是复平面上的整函数，而没有分支。

正弦的数学定义是

sin z =
eiz
-e-iz
2i

示例

运行此代码
#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1, 0); // 表现同沿着实轴的实正弦
    std::cout << "sin" << z << " = " << std::sin(z)
              << " ( sin(1) = " << std::sin(1) << ")\n";

    std::complex<double> z2(0, 1); // 表现同沿着虚轴的 sinh
    std::cout << "sin" << z2 << " = " << std::sin(z2)
              << " (sinh(1) = " << std::sinh(1) << ")\n";
}

输出： 

sin(1.000000,0.000000) = (0.841471,0.000000) ( sin(1) = 0.841471)
sin(0.000000,1.000000) = (0.000000,1.175201) (sinh(1) = 1.175201)
