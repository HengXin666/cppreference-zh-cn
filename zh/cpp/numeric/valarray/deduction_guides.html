推导指引 (C++17)
 
在标头 <valarray> 定义 
template< typename T, std::size_t cnt >
valarray( const T(&)[cnt], std::size_t ) -> valarray<T>;
(C++17 起)

为 std::valarray 提供此推导指引以允许从数组和大小推导（注意从指针和大小推导已为隐式指引所涵盖）。

示例

运行此代码
#include <iostream>
#include <valarray>

int main()
{
    int a[] = {1, 2, 3, 4};
    std::valarray va(a, 3); // 使用显式推导指引
    for (int x : va)
        std::cout << x << ' ';
    std::cout << '\n';
}

输出： 

1 2 3
