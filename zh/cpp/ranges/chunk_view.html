chunk_view 接收单个视图 view 与数值 n 并基于原视图产生一系列视图（区块 ﻿），除了最后一个区块，每个区块 ﻿的大小都为 n。这些区块是原视图元素按顺序排列的，非重叠，连续的子范围。

令 s 为原视图的大小，如果 s 不是 n 的倍数，则最后一个生成的视图（最后区块）大小正好为 s % n（余数）。否则，包括最后一个的每个区块 ﻿大小都为 n。

生成视图的大小为 /*div-ceil*/(s)。

如果 n 不大于 0 则其行为未定义。

1) 支持仅实现了 input_range 的底层视图 V 的实现。
2) 支持实现了 forward_range 或更强的底层视图 V 的部分特化。仅当底层视图 V 实现 forward_range、common_range、sized_range 或非 bidirectional_range 时实现 common_range。
3) views::chunk 指代一个 范围适配器对象 (RangeAdaptorObject) 。给定子表达式 e 和 n， views::chunk(e, n) 表达式等价于 chunk_view(e, n)。
4) 计算大于等于 num 除以 denom 的商的最小整数值，等价于： 
I r = num / denom;
if (num % denom)
    ++r;
return r;

辅助模板

template< class V >
constexpr bool ranges::enable_borrowed_range<chunk_view<V>> =
    ranges::forward_range<V> && ranges::enable_borrowed_range<V>;
(C++23 起)

ranges::enable_borrowed_range 的这项特化使得当底层视图 V 同时满足 forward_range 和 borrowed_range 时，chunk_view 满足borrowed_range

注解

如果 V 实现 input_range (1)，那么 chunk_view 的迭代器为一个专有类型：outer_iterator::value_type 且它本身就是输入视图。

如果 V 实现 forward_range 或更强的范围 (2)，那么 chunk_view 的 value_type 遵循 views::take 的规定。

如果 V 实现 bidirectional_range 或更强的范围 (2)，那么由于需要正确计算最后一个块的大小（从尾迭代器开始），因此底层范围类型 V 必须为 sized_range。

示例

运行此代码
#include <algorithm>
#include <initializer_list>
#include <iostream>
#include <ranges>

auto print_subrange = [](std::ranges::viewable_range auto&& r)
{
    std::cout << '[';
    for (int pos{}; auto elem : r)
        std::cout << (pos++ ? " " : "") << elem;
    std::cout << "] ";
};

int main()
{
    const auto v = {1, 2, 3, 4, 5, 6};

    for (const unsigned width : std::views::iota(1U, 2U + v.size()))
    {
        auto const chunks = v | std::views::chunk(width);
        std::cout << "chunk(" << width << "): ";
        std::ranges::for_each(chunks, print_subrange);
        std::cout << '\n';
    }
}

输出：

chunk(2): [1 2] [3 4] [5 6]
chunk(3): [1 2 3] [4 5 6]
chunk(4): [1 2 3 4] [5 6]
chunk(5): [1 2 3 4 5] [6]
chunk(6): [1 2 3 4 5 6]
chunk(7): [1 2 3 4 5 6]
