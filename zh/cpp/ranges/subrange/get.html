在标头 <ranges> 定义 
template< std::size_t N, class I, class S, ranges::subrange_kind K >
    requires ((N == 0 && std::copyable<I>) || N == 1)
constexpr auto get( const ranges::subrange<I, S, K>& r );
(1) (C++20 起) 
template< std::size_t N, class I, class S, ranges::subrange_kind K >
    requires (N < 2)
constexpr auto get( ranges::subrange<I, S, K>&& r );
(2) (C++20 起) 
namespace std { using ranges::get; }
(3) (C++20 起)

提供结构化绑定支持。

1) 分别在 N == 0 或 N == 1 时从 subrange 左值（或 const 右值）获得迭代器或哨位。
2) 同 (1)，但它接收非 const subrange 右值。
3) 将重载 (1,2) 导入命名空间 std，这简化其使用并使得每个拥有可复制迭代器的 subrange 均为对偶式类型。

参数

r - subrange

返回值

1,2) 在 N 是 0 时返回 r.begin()。否则（N 是 1）返回 r.end()。

示例

运行此代码
#include <array>
#include <iostream>
#include <iterator>
#include <ranges>

int main()
{
    std::array a{1, -2, 3, -4};
    
    std::ranges::subrange sub_a{std::next(a.begin()), std::prev(a.end())};
    std::cout << *std::ranges::get<0>(sub_a) << ' '   // == *(begin(a) + 1)
              << *std::ranges::get<1>(sub_a) << '\n'; // == *(end(a) - 1)
    
    *std::get<0>(sub_a) = 42; // OK
//  *std::get<2>(sub_a) = 13; // 错误：索引只能是 0 或 1
}

输出： 

-2 -4
