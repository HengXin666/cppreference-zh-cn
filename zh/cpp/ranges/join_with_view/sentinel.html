template< bool Const >
class /*sentinel*/
(仅用于阐述*)

ranges::join_with_view<V, Pattern>::sentinel 是 ranges::join_with_view<V, Pattern> 的 end() 返回的哨位的类型。

如果某个迭代器与哨位比较相等，那么该迭代器是尾后迭代器。

模板形参

Const - 哨位是否对应常迭代器
