计算迭代器与哨位之间的距离（其中的块数量）。

令 parent_ 为指向外围 chunk_view 的底层迭代器。

1) 等价于： 
const auto dist = ranges::end(i.parent_->base_) - *i.parent_->current_;
if (dist < i.parent_->remainder_)
    return dist == 0 ? 0 : 1;
return /*div-ceil*/(dist - i.parent_->remainder_, i.parent_->n_) + 1;
2) 等价于：return -(s - i);。

这些函数对常规的无限定或有限定查找不可见，而只能在 std::ranges::chunk_view::outer-iterator 为实参的关联类时由实参依赖查找找到。

参数

i - 迭代器
s - 哨位

返回值

给定迭代器与哨位之间的距离。
