推导指引
 
在标头 <ranges> 定义 
template< class R >
drop_view( R&&, ranges::range_difference_t<R> ) -> drop_view<views::all_t<R>>;
(C++20 起)

为 std::ranges::drop_view 提供一个推导指引以允许从 range 和元素数推导。

若 R 为 view 则推导的类型为 drop_view<R>；否则推导的类型通常为 drop_view<ranges::ref_view<R>>。
