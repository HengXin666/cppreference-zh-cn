调用签名
 
template< class T >
    requires /* 见下文 */
constexpr /* 见下文 */ auto cbegin( T&& t );
(C++20 起)

返回指向 const 限定的实参的首元素的迭代器。

(C++23 前)

返回指向实参的首元素的常量迭代器。

(C++23 起)

令 CT

  • 若实参为左值（即 T 为左值引用类型）则为 const std::remove_reference_t<T>&，
  • 否则为 const T。

对 ranges::cbegin 的调用表达式等价于 ranges::begin(static_cast<CT&&>(t))。

(C++23 前)

若实参为左值或者 ranges::enable_borrowed_range<std::remove_cv_t<T>> 为 true，则对 ranges::cbegin 的调用表达式等价于：

  • std::const_iterator<decltype(U)>(U) 对于某个表达式 U 等价于 ranges::begin(possibly-const-range(t)。

所有其他情况下，对 ranges::cbegin 的调用都非良构，这会在调用出现于模板实例化的立即语境中时导致代换失败。

(C++23 起)

所有情况下，返回类型都实现 std::input_or_output_iterator 和 constant-iterator(C++23 起)。

定制点对象

名字 ranges::cbegin 代表一个定制点对象，它是某个字面 semiregular 类类型的 const 函数对象。 细节参见定制点对象 (CustomizationPointObject) 。

注解

对于 T 类型的左值范围 e，ranges::cbegin(e) 等价于

ranges::begin(std::as_const(e))。

(C++23 前)
  • ranges::begin(e) 若 T 实现 constant_range。
  • 否则，ranges::begin(std::as_const(e)) 若 const T 实现 constant_range。
  • 否则，std::basic_const_iterator(ranges::begin(e))。
 (C++23 起)

示例

运行此代码
#include <cassert>
#include <ranges>
#include <vector>

int main() 
{
    std::vector v{3, 1, 4};
    auto vi = std::ranges::cbegin(v);
    assert(3 == *vi);
    ++vi; // OK，可以改动常量迭代器对象
    assert(1 == *vi);
    // *vi = 13; // 错误：常量迭代器指向不可改动元素

    int a[]{3, 1, 4};
    auto ai = std::ranges::cbegin(a); // cbegin 也可以对 C 数组
    assert(3 == *ai and *(ai + 1) == 1);
    // *ai = 13; // 错误：只读变量不可赋值
}
