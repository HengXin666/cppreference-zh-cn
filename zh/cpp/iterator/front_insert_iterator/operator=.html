向容器插入给定的 value。

1) 导致 container->push_front(value)。
2) 导致 container->push_front(std::move(value))。

参数

value - 要插入的值

返回值

*this

示例

运行此代码
#include <deque>
#include <iostream>
#include <iterator>

int main()
{
    std::deque<int> q;
    std::front_insert_iterator<std::deque<int>> it(q);

    for (int i = 0; i < 10; ++i)
        it = i; // 调用 q.push_front(i)

    for (auto& elem : q)
        std::cout << elem << ' ';
    std::cout << '\n';
}

输出： 

9 8 7 6 5 4 3 2 1 0
