在标头 <iterator> 定义 
template< class I >
    concept input_iterator =
        std::input_or_output_iterator<I> &&
        std::indirectly_readable<I> &&
        requires { typename /*ITER_CONCEPT*/<I>; } &&
        std::derived_from</*ITER_CONCEPT*/<I>, std::input_iterator_tag>;
(C++20 起)

input_iterator 概念是 input_or_output_iterator 的精化，添加了能读取被引用值的要求（经由 indirectly_readable），和存在迭代器概念标签的要求。

迭代器概念确定

此概念的定义通过仅用于阐述的别名模板 /*ITER_CONCEPT*/ 说明。

为确定 /*ITER_CONCEPT*/<I>，令 ITER_TRAITS<I> 在特化 std::iterator_traits<I> 从主模板生成时代表 I，否则代表 std::iterator_traits<I>：

  • 如果 ITER_TRAITS<I>::iterator_concept 合法并指名类型，那么 /*ITER_CONCEPT*/<I> 代表该类型。
  • 否则，如果 ITER_TRAITS<I>::iterator_category 合法并指名类型，那么 /*ITER_CONCEPT*/<I> 代表该类型。
    （亦即，std::derived_from</*ITER_CONCEPT*/<I>, std::input_iterator_tag> 假定为 true。）
  • 否则，如果 std::iterator_traits<I> 从主模板生成，那么 /*ITER_CONCEPT*/<I> 指代 std::random_access_iterator_tag。
  • 否则 /*ITER_CONCEPT*/<I> 不代表类型并导致替换失败。

注解

不同于老式输入迭代器 (LegacyInputIterator) 要求，input_iterator 概念不要求 equality_comparable，因为输入迭代器常与哨位比较。

示例

最小化的输入迭代器。 

#include <cstddef>
#include <iterator>

struct SimpleInputIterator
{
    using difference_type = std::ptrdiff_t;
    using value_type = int;

    int operator*() const;

    SimpleInputIterator& operator++();
    void operator++(int) { ++*this; }
};

static_assert(std::input_iterator<SimpleInputIterator>);
