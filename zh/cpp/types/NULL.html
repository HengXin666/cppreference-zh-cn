宏 NULL 是由实现定义的空指针常量。

可能的实现

#define NULL 0
// C++11 起
#define NULL nullptr

注解

C 中，宏 NULL 可以拥有类型 void*，但这在 C++ 中不允许，因为空指针常量不能具有该类型。

示例

运行此代码
#include <cstddef>
#include <iostream>
#include <type_traits>
#include <typeinfo>

class S;

int main()
{
    int* p = NULL;
    int* p2 = static_cast<std::nullptr_t>(NULL);
    void(*f)(int) = NULL;
    int S::*mp = NULL;
    void(S::*mfp)(int) = NULL;
    auto nullvar = NULL; // 以 gcc/clang 编译时可能会触发警告
    
    std::cout << "nullvar 的类型是 " << typeid(nullvar).name() << '\n';
    
    if constexpr(std::is_same_v<decltype(NULL), std::nullptr_t>)
        std::cout << "NULL 以 std::nullptr_t 类型实现\n";
    else
        std::cout << "NULL 以整数类型实现\n";

    [](...){}(p, p2, f, mp, mfp); // < 抑制“未使用变量”警告
}

可能的输出： 

nullvar 的类型是 long
NULL 以整数类型实现
