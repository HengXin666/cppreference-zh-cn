用法

  • short int 类型: 与 short 结合时用于该类型的声明
  • unsigned short int 类型: 与 unsigned 和 short 结合时用于该类型的声明
  • int 类型: 用于该类型的声明
  • unsigned int 类型: 与 unsigned 结合时用于该类型的声明
  • long int 类型: 与 long 结合时用于该类型的声明
  • unsigned long int 类型: 与 unsigned 和 long 结合时用于该类型的声明
  • long long int 类型: 与两个 long 结合时用于该类型的声明
  • unsigned long long int 类型: 与 unsigned 和两个 long 结合时用于该类型的声明
 (C++11 起)

参阅

  • 基础类型：void、std::nullptr_t(C++11 起)。
    • 整数类型：int。修饰符：signed、unsigned、short、long。
      • 布尔类型: bool。布尔字面量: false、true。
      • 字符类型：char、char8_t(C++20 起)、char16_t、char32_t(C++11 起)、wchar_t。
    • 浮点数类型：float、double。
