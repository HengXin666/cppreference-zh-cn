(5) (C++20 起) 
template< class TimeZonePtrOrName, class Duration, class TimeZonePtr2 >
zoned_time( TimeZonePtrOrName&&, std::chrono::zoned_time<Duration, TimeZonePtr2>,

    -> zoned_time<std::common_type_t<Duration, std::chrono::seconds>, /* 见下文 */>;
(6) (C++20 起)

为 zoned_time 提供六个推导指引。它们把 Duration 正规化为最小分辨率为 std::chrono::seconds，并提供用对可转换成 std::string_view 的类型的指定时区名的正确处理。

3-6) 若 std::is_convertible_v<TimeZonePtrOrName, std::string_view> 为 true，则推导的第二模板实参为 const std::chrono::time_zone*。否则为 std::remove_cvref_t<TimeZonePtrOrName>。
