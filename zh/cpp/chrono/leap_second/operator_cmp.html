(12) (C++20 起)

比较对象 x 与 y 所表示的日期和时间。

(12) 的返回类型从 x.date() <=> y 推导，从而为 std::chrono::seconds 与 Duration 的三路比较结果类型。

!= 运算符从 operator== 运算符合成。

返回值

1) x.date() == y.date()
2) x.date() <=> y.date()
3) x.date() == y
4) x.date() < y
5) x < y.date()
6) x.date() > y
7) x > y.date()
8) x.date() <= y
9) x <= y.date()
10) x.date() >= y
11) x >= y.date()
