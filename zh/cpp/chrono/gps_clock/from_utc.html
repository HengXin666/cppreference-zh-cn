template< class Duration >
static std::chrono::gps_time<std::common_type_t<Duration, std::chrono::seconds>>
    from_utc( const std::chrono::utc_time<Duration>& ) noexcept;
(C++20 起)

转换 utc_time t 为表示相同时间点的 gps_time。

返回值

与 t 表示相同时间点的 std::chrono::gps_time，如同以从 t.time_since_epoch() 构造返回类型的值，并减去 315964809s 一般计算。（315964809 是时钟 gps_clock 的纪元 1980-01-06 00:00:00 UTC 和时钟 utc_clock 的纪元 1970-01-01 00:00:00 UTC 间的秒数。）
