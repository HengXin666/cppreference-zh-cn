regex_error& operator=( const regex_error& other ) noexcept;
(C++11 起)

以 other 的内容赋值。若 *this 与 other 均拥有动态类型 std::regex_error 则赋值后 std::strcmp(what(), other.what()) == 0。

参数

other - 用以赋值的另一 regex_error 对象

返回值

*this
