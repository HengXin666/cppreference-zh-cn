swap(std::match_results)
 
在标头 <regex> 定义 
template< class BidirIt, class Alloc >
void swap( match_results<BidirIt,Alloc>& x1,
           match_results<BidirIt,Alloc>& x2 ) noexcept;
(C++11 起)

为 std::match_results 特化 std::swap 算法。交换 x1 与 x2 的内容。相当于调用 x1.swap(x2)。

参数

x1, x2 - 要交换内容的 match_results 对象
类型要求
-
BidirIt 必须满足老式双向迭代器 (LegacyBidirectionalIterator) 。
-
Alloc 必须满足分配器 (Allocator) 。

返回值

（无）
