difference_type length( size_type n = 0 ) const;
(C++11 起)

返回指定子匹配的长度。

若 n == 0，则返回整个匹配的表达式的长度。

若 n > 0 && n < size()，则返回第 n 个子匹配的长度。

若 n >= size()，则返回未匹配的长度。

调用等价于 (*this)[n].length()。

ready() 必须为 true。否则，其行为未定义。

参数

n - 指定要检验哪个匹配的整数

返回值

指定的匹配或子匹配的长度。
