在标头 <spanstream> 定义 
template< class CharT, class Traits >
void swap( std::basic_spanbuf<CharT, Traits>& lhs,
           std::basic_spanbuf<CharT, Traits>& rhs );
(C++23 起)

为 std::basic_spanbuf 重载 std::swap 算法。交换 lhs 与 rhs 的状态。等价于 lhs.swap(rhs);。

参数

lhs, rhs - 要交换状态的 std::basic_spanbuf 对象

返回值

（无）

异常

可能会抛出由实现定义的异常。
