在标头 <fstream> 定义 
template< 
    class CharT, 
    class Traits = std::char_traits<CharT>
> class basic_ofstream : public std::basic_ostream<CharT, Traits>

类模板 basic_ofstream 实现文件上基于流的高层输出操作。它将 std::basic_ostream 的高层接口赋予基于文件的流缓冲（std::basic_filebuf）。

std::basic_ofstream 的典型实现只保有一个非派生成员：一个 std::basic_filebuf<CharT, Traits> 的实例。

示例

运行此代码
#include <fstream>
#include <iostream>
#include <string>

int main()
{
    std::string filename = "Test.b";
    {
        std::ofstream ostrm(filename, std::ios::binary);
        double d = 3.14;
        ostrm.write(reinterpret_cast<char*>(&d), sizeof d); // 二进制输出
        ostrm << 123 << "abc" << '\n';                      // 文本输出
    }
    
    // 回读
    std::ifstream istrm(filename, std::ios::binary);
    double d;
    istrm.read(reinterpret_cast<char*>(&d), sizeof d);
    int n;
    std::string s;
    istrm >> n >> s;
    std::cout << "回读：" << d << " " << n << " " << s << '\n';
}

输出： 

回读：3.14 123 abc
