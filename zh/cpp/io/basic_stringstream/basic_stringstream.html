构造新的字符串流。

给定

  • base_type 为 std::basic_iostream<CharT, Traits>，
  • buf_type 为 std::basic_stringbuf<CharT, Traits, Allocator>，

按以下方式初始化基类 std::basic_iostream 和仅用于阐述的数据成员 sb。

(2) buf_type(std::ios_base::in | std::ios_base::out)
(3) buf_type(str, mode)
(4) buf_type(std::move(str), mode)
(5) buf_type(mode, a)
(6) buf_type(str, mode, a)

(8) buf_type(str, mode)
(9) std::addressof(sb) {t, mode, Allocator()}

(12) 从 other 的 std::basic_iostream 基类

8) 此重载只有在 std::is_same_v<SAlloc, Allocator> 是 false 时才会参与重载决议。
9-11) 这些重载只有在 std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> 是 true 时才会参与重载决议。

参数

str - 用作字符串流的初始内容的字符串
t - 用作字符串流的初始内容的对象（可转换到 std::basic_string_view）
a - 用于分配字符串流的内容的分配器
mode - 指定流打开模式。它是一种位掩码类型 (BitmaskType) ，定义了下列常量：
常量 解释
app 每次写入前寻位到流结尾
binary 以二进制模式打开
in 为读打开
out 为写打开
trunc 在打开时舍弃流的内容
ate 打开后立即寻位到流结尾
noreplace (C++23) 以独占模式打开
other - 用作源的另一字符串流

注解

在短的循环中，例如用于字符串转换时，构造单次使用的 basic_stringstream 对象，开销可能显著高于调用 str() 并复用同一对象。

功能特性测试宏 值 标准 功能特性
__cpp_lib_sstream_from_string_view 202306L (C++26) 字符串流的 std::string_view 接口，(9-11)

示例

运行此代码
#include <iostream>
#include <sstream>

int main()
{
    // 默认构造函数（输入/输出流）
    std::stringstream buf1;
    buf1 << 7;
    int n = 0;
    buf1 >> n;
    std::cout << "buf1 = " << buf1.str() << " n = " << n << '\n';
    
    // 输入流
    std::istringstream inbuf("-10");
    inbuf >> n;
    std::cout << "n = " << n << '\n';
    
    // 追加模式的输出流（C++11）
    std::ostringstream buf2("test", std::ios_base::ate);
    buf2 << '1';
    std::cout << buf2.str() << '\n';
}

输出： 

buf1 = 7 n = 7
n = -10
test1
