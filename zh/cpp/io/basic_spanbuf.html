在标头 <spanstream> 定义 
template<
    class CharT,
    class Traits = std::char_traits<CharT>
> class basic_spanbuf
    : public std::basic_streambuf<CharT, Traits>
(C++23 起)

std::basic_spanbuf 是一个关联内存中固定位置的任意字符序列的 std::basic_streambuf，它能从 std::span<CharT> 初始化，并能被用作 std::span<CharT> 的实例。

std::basic_spanbuf 进行固定缓冲区上的输入/输出，因此它在耗尽底层缓冲区时不会尝试获得新的缓冲区。

提供了几个针对常用字符类型的 typedef：

注解

std::basic_spanbuf 不占有底层缓冲区。

程序员负责在使用 std::basic_spanbuf 时确保它的缓冲区处于它的生存期中。多于一个线程在通过不同的 std::basic_spanbuf 对象操作同一底层缓冲区时可能需要额外的同步。
