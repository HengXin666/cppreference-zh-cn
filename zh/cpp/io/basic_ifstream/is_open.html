bool is_open() const;

检查文件流是否有关联文件。

相当于调用 rdbuf()->is_open()。

参数

（无）

返回值

文件流有关联文件时返回 true，否则返回 false。

示例

运行此代码
#include <fstream>
#include <iostream>
#include <string>

// 此文件名为 main.cpp

bool file_exists(const std::string& str)
{
    std::ifstream fs(str);
    return fs.is_open();
}

int main()
{
    std::boolalpha(std::cout);
    std::cout << file_exists("main.cpp")  << '\n'
              << file_exists("strange_file") << '\n';
}

可能的输出： 

true
false
