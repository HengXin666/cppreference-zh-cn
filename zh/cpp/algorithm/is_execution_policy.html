在标头 <execution> 定义 
template< class T >
struct is_execution_policy;
(C++17 起)

检查 T 是否为标准或实现定义的执行策略类型。

若 T 是标准执行策略类型或实现定义的执行策略类型，则提供等于 true 的成员常量 value。否则，value 等于 false。

如果程序添加了 std::is_execution_policy 或 std::is_execution_policy_v 的特化，那么行为未定义。

模板形参

T - 要检查的类型

辅助模板

在标头 <execution> 定义 
template< class T >
constexpr bool is_execution_policy_v = std::is_execution_policy<T>::value;
(C++17 起)

继承自 std::integral_constant
