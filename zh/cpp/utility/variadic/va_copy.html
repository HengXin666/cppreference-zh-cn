(C++11)
va_end
va_list
 
在标头 <cstdarg> 定义 
void va_copy( std::va_list dest, std::va_list src );
(C++11 起)

va_copy 宏复制 src 到 dest。

va_end 应当在函数返回前或任何 dest 的后继重初始化（通过对 va_start 或 va_copy 的调用）前对 dest 调用。

参数

dest - 要初始化的 va_list 类型实例
src - 将用于初始化 dest 的源 va_list

展开值

（无）

示例

运行此代码
#include <cmath>
#include <cstdarg>
#include <iostream>

double sample_stddev(int count, ...) 
{
    double sum = 0;
    std::va_list args1;
    va_start(args1, count);
    std::va_list args2;
    va_copy(args2, args1);
    for (int i = 0; i < count; ++i)
    {
        double num = va_arg(args1, double);
        sum += num;
    }
    va_end(args1);
    double mean = sum / count;

    double sum_sq_diff = 0;
    for (int i = 0; i < count; ++i)
    {
        double num = va_arg(args2, double);
        sum_sq_diff += (num - mean) * (num - mean);
    }
    va_end(args2);
    return std::sqrt(sum_sq_diff / count);
}

int main() 
{
    std::cout << sample_stddev(4, 25.0, 27.3, 26.9, 25.7) << '\n';
}

输出： 

0.920258
